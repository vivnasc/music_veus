# Álbum 5 — **Pés Descalços** (Medo)

> Função do álbum: enraizar pelo sensorial. Voltar ao corpo através do que toca a pele.
> Hora interior: manhã com orvalho.

**Os 7 conceitos do álbum:**

| # | Posição | Conceito |
|---|---|---|
| 5.1 | Chegada | **Deixei de habitar a pele** — diagnóstico de afastamento |
| 5.2 | Reconhecimento | **A pele é fronteira viva** — não barreira, mas órgão de relação |
| 5.3 | Aprofundamento | **Tocar é também ser tocada** — reciprocidade sensorial |
| 5.4 | Centro | **Volto pelo corpo, não pela cabeça** — caminho corpo-primeiro |
| 5.5 | Habitação | **Sou habitante deste corpo** — moradora, não passageira |
| 5.6 | Despedida | **Levo a sensibilidade para o dia** — atenção sensorial activa |
| 5.7 | Dissolução | **A pele também se dissolve** — aceitar a permeabilidade |

---
